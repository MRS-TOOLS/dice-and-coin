# DICE & COIN

スマートフォン向けWebツール。3Dダイスを振る／コインをトスするだけのシンプルなツールです。

## ファイル構成

```
index.html   画面構造
style.css    デザイン・レイアウト・アニメーション
script.js    ロジック（乱数生成・状態管理・localStorage）
```

## 機能

- DICE：個数1〜3、D6 / D8 / D10 / D12 / D20 / D100から選択
- D100は赤い十の位ダイスと青い一の位ダイスの2個固定（00＋0は100）
- ダイスは角を軽く面取りした実際の多面体形状をコードで生成し、緑のテーブルと木製フレーム上で物理演算
- 出目は `crypto.getRandomValues()` で先に公平に決定し、同一条件の事前物理計算で面表示を準備
- 停止後の位置移動・回転補正は行わず、物理演算で止まった位置と角度をそのまま表示
- COIN：枚数1〜3
- COINの初期コインはリンカーン・メモリアルペニー。表裏の画像と厚みのある銅色の側面を使い、同じ緑の盤面で3Dトス（跳ね返り）
- コインの表裏は公平な乱数で先に決定し、事前の物理計算で静止する側に絵柄を対応させます。停止後の回転補正は行いません
- WebGL・画像を読み込めない場合は2D表示へ切り替え、結果と履歴は利用できます
- 実行結果を最大10件まで履歴保存（localStorage）
- 設定値もlocalStorageに保存し、再訪問時に復元
- ダイス用の画像・3Dモデルアセット不使用

## 3Dライブラリ

- Three.js `0.186.1`：3D描画
- cannon-es `0.20.0`：物理演算

ビルド工程を増やさないため、バージョン固定したCDN版を読み込みます。読み込みに失敗した場合も、数値の出目と履歴機能は利用できます。

## 公開方法

`index.html` がエントリーポイントです。
現在の公開先は `MRS-TOOLS/TOOLS-home` リポジトリ内の `dice-coin` フォルダです。
このリポジトリを開発元とし、公開時に完成版を公開用リポジトリへ反映します。

## 注意

- 画面最下部の広告枠には、MRS WORKS共通テンプレートの広告コード（admax）をそのまま使用しています。
- 3Dダイス、木目、テーブル用の画像・3Dモデルアセットは使用せず、形状と面表示をJavaScriptで生成しています。
- `assets/images/lincoln-memorial-heads.webp` と `lincoln-memorial-tails.webp` は、1964年のリンカーン・メモリアルペニーを参考にAI生成したゲーム用画像です。リンカーンを表、リンカーン記念堂を裏として扱います。画像は実物の厳密な複製ではありません。3Dの側面形状はコードで生成します。
- `assets/images/washington-quarter-heads.webp` と `washington-quarter-tails.webp` は、1965年のワシントン・クォーター（旧来のワシの裏面）を参考にAI生成したゲーム用画像です。将来の称号解放用に保持し、現在の初期コインや選択肢には使いません。
- `assets/images/liberty-heads.webp` と `liberty-tails.webp` は、1900年リバティヘッド20ドル金貨（ダブルイーグル）を参考にAI生成したゲーム用画像です。将来の称号解放用に保持し、現在の初期コインや選択肢としては使いません。称号条件・解放処理・コイン選択は未実装です。
