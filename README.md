# DICE & COIN

スマートフォン向けWebツール。3Dダイスを振る／コインをトスするだけのシンプルなツールです。

## ファイル構成

```
index.html   画面構造
style.css    デザイン・レイアウト・アニメーション
script.js    起動・画面切替・設定／履歴UI・各処理の連携
js/dice.js   ダイスの形状・描画・抽選
js/coin.js   コインの描画・抽選・表裏強調
js/scene.js  共通の盤面・木枠・物理環境
js/shared.js 共通設定・状態・保存・ライブラリ読み込み
```

本体は5つのESモジュールで構成し、`script.js` がダイス・コインのコントローラーを作成してUIと接続します。コントローラーの3D状態はそれぞれの内部で保持し、共通モジュールからUIへ逆向きのimportは行いません。追加ビルドは不要です。

モジュールの追加・変更時は `index.html` の入口、各importの `?v=`、`sw.js` のキャッシュ版と対象ファイルを同一リリースとして更新してください。分割後の4ファイルも初回からまとめてキャッシュし、未使用のCOINもオフラインで起動できます。

## 機能

- DICE：個数1〜3、D6 / D8 / D10 / D12 / D20 / D100から選択
- D100は赤い十の位ダイスと青い一の位ダイスの2個固定（00＋0は100）
- ダイスは角を軽く面取りした実際の多面体形状をコードで生成し、緑のテーブルと木製フレーム上で物理演算
- 出目は `crypto.getRandomValues()` で先に公平に決定し、同一条件の事前物理計算で面表示を準備
- 停止後の位置移動・回転補正は行わず、物理演算で止まった位置と角度をそのまま表示
- COIN：枚数1〜3
- COINの初期コインはリンカーン・メモリアルペニー。表裏の画像と厚みのある銅色の側面を使い、同じ緑の盤面で3Dトス（跳ね返り）
- コインの表裏は公平な乱数で先に決定し、事前の物理計算で静止する側に絵柄を対応させます。停止後の回転補正は行いません
- WebGL・画像を読み込めない場合は2D表示へ切り替え、結果と履歴は利用できます
- 実行結果を最大10件まで履歴保存（localStorage）
- 設定値もlocalStorageに保存し、再訪問時に復元
- ダイス用の画像・3Dモデルアセット不使用

## 3Dライブラリ

- Three.js `0.186.1`：3D描画
- cannon-es `0.20.0`：物理演算

バージョン固定した配布ファイルを縮小し、MITライセンスとともに `assets/vendor/` に同梱しています。Three.jsは `three.module.js` と依存する `three.core.js` の両方を使用します。配信時のビルド工程は不要です。

## PWA・オフライン

- iPhoneのSafariで共有メニューから「ホーム画面に追加」すると、専用アイコン・独立した画面で起動できます。対応ブラウザではインストール機能も利用できます。
- 初回はオンラインで開き、Service Workerのインストール（必要なファイルの保存）が完了するまで待ってください。その後はオフラインで起動・3Dダイス・3Dコイン・設定・履歴を使用できます。WebGL非対応時の代替表示も利用できます。
- ブラウザや端末によって保存データを消去された場合は、再度オンラインでの読み込みが必要です。
- 広告とMRS TOOLSへの外部リンクはオンライン時のみ利用できます。広告や外部サイトはキャッシュしません。
- 更新は新しいファイル一式の保存後、開いているアプリ画面をすべて閉じた後に有効になります。投げている途中の強制再読み込みは行いません。
- **更新手順：** キャッシュ対象を変更した際は `sw.js` の `CACHE_NAME` のバージョンを必ず更新します。必要な追加ファイルは `ASSETS` に登録します。失敗した新規キャッシュは削除し、既存版は維持します。
- 追加ファイル：`manifest.webmanifest` はアプリ情報、`pwa.js` は登録処理、`sw.js` はオフライン保存・更新を担当します。`assets/icons/` に通常・Apple・マスク対応アイコンを保存しています。

## 公開方法

`index.html` がエントリーポイントです。
この独立リポジトリ `MRS-TOOLS/dice-and-coin` をCloudflare Pagesに接続し、ルートをそのまま配信します（ビルド不要）。本番URLは https://dice-and-coin.pages.dev/ です。Service WorkerはHTTPS、または開発用localhostで動作します。

## 注意

- 画面最下部の広告枠には、MRS WORKS共通テンプレートの広告コード（admax）をそのまま使用しています。
- 3Dダイス、木目、テーブル用の画像・3Dモデルアセットは使用せず、形状と面表示をJavaScriptで生成しています。
- `assets/images/lincoln-memorial-heads.webp` と `lincoln-memorial-tails.webp` は、1964年のリンカーン・メモリアルペニーを参考にAI生成したゲーム用画像です。リンカーンを表、リンカーン記念堂を裏として扱います。画像は実物の厳密な複製ではありません。3Dの側面形状はコードで生成します。
- `assets/images/washington-quarter-heads.webp` と `washington-quarter-tails.webp` は、1965年のワシントン・クォーター（旧来のワシの裏面）を参考にAI生成したゲーム用画像です。将来の称号解放用に保持し、現在の初期コインや選択肢には使いません。
- `assets/images/liberty-heads.webp` と `liberty-tails.webp` は、1900年リバティヘッド20ドル金貨（ダブルイーグル）を参考にAI生成したゲーム用画像です。将来の称号解放用に保持し、現在の初期コインや選択肢としては使いません。称号条件・解放処理・コイン選択は未実装です。

## 弱回線耐性（2026-10-20）

通常オンライン・低速／不安定通信・完全オフラインの3状態で、取得済み本体から起動します。アプリmoduleは全要素と広告コンテナを配置した後にasync実行し、DOMContentLoadedや広告応答を待ちません。独立したpwa.jsも広告scriptより前に実行します。広告タグ・IDは維持します。

シェルは全ファイル取得・保存後に採用します。更新SWは既存画面をすべて閉じるまで待ち、投擲中に強制切替しません。キャッシュ欠損時の取得は接続・本文を含め8秒で打ち切り、入口の取得失敗には再試行案内を返します。キャッシュを通信結果で個別更新しません。キャッシュ版・HTML参照・SW対象リストは同時に更新してください。

3Dライブラリ・コイン画像の既存8秒制限と数値表示へのフォールバック、設定・履歴の保存キー／形式、広告、Cloudflare設定は維持します。旧キャッシュ削除はdice-and-coin-の範囲だけで、localStorageは削除しません。初回未キャッシュ・旧SW制御中には今回の新SWの制限は適用されません。

テストはNode.js 24以降で、`npm install --no-save --package-lock=false jsdom@30.1.3` の後に `node --experimental-vm-modules --test tests/*.test.cjs`。通信・DOM・module起動・3Dにはモックを使います。iPhone / Safari実機・ホーム画面起動・実広告・実3D描画は別途確認が必要です。
